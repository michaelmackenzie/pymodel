# Binned example model card for the hfmodel backend.
#
# Signal: Gaussian(mu=105, sigma=0.35), yield=12
# Background: Exponential(lam=-0.25), yield=80
# Observable: mass in [100, 110], 20 uniform bins
# Observed counts are identical to the zmodel and roomodel binned examples.
#
# Systematics are encoded directly in the workspace JSON:
#   lumi     normsys ±5%  on both signal and background
#   bkg_norm normsys ±10% on background only
#
# Step 1: generate the workspace:
#   cd examples/hfmodel && python simple_shapes_binned.py
# Step 2: build the model:
#   pymodel hfmodel build simple_shapes_binned_card.txt model_binned.json
# Step 3: run the analysis:
#   pymodel hfmodel analyze -m model_binned.json
